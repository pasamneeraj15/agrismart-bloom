# AgriSmart Bloom

Build AgriSmart, a comprehensive smart farming web application with a nature-inspired agricultural theme (clean greens, soft shadows, rounded cards). Include: 1) Landing page with hero, tagline 'Smart Farming, Better Future', and navigation; 2) Authentication (Login and Registration forms); 3) Home Dashboard with farm overview metrics, weather summary card, pending tasks, and recommendations; 4) Crops catalog with search, filters (Wheat, Rice, Cotton, Tomato, Potato, etc.), and detailed growing/pest/soil profiles; 5) Pesticides directory with crop filters, target pests, dosage/acre, and safety guidelines; 6) Fertilizers guide categorized into Organic, Inorganic, and Biofertilizers; 7) Weather forecast dashboard with 5-day forecast and farming advisories; 8) Plant Scan & Disease Detection interactive demo with leaf image upload, scanning simulation, and diagnosis/recommendations; 9) Farm Alerts & Notifications center; 10) Settings & farmer profile page. Ensure full responsiveness with desktop sidebar and mobile navigation.
